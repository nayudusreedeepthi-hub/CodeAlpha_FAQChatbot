# CodeAlpha_FAQChatbot
A simple NLP-based chatbot developed for the CodeAlpha AI Internship. It uses TF-IDF Vectorization and Cosine Similarity to match user queries with predefined FAQs and provide relevant answers. Built using Python, Streamlit, Pandas, and Scikit-learn with an interactive and user-friendly interface.
